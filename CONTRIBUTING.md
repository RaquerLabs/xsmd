# Contributing Workflow

1. Fork the repository. Then clone it.
2. Make your changes. Write code under `internal/` or in the entry points in `cmd/`.
3. Write tests. Add unit tests inside `_test.go` files.
4. Format your files with `mise run format`. Run the tests with `mise run test`.
5. Update the documentation in `README.md` and `docs/`.
6. Update the `CHANGELOG.md` file.
7. Submit a PR.
